# 来源与更新依据

## law-2025

- 标题：中华人民共和国传染病防治法
- 发布日期：2025-05-12
- 通过日期：2025-04-30
- 施行日期：2025-09-01
- 来源：国家疾病预防控制局转载中国政府网
- URL：https://www.ndcpa.gov.cn/jbkzzx/c100081/common/content/content_1921828571641712640.html

本来源用于建立 2025 年新版法律下的甲类、乙类、丙类目录基线。法律第三条列出甲类 2 种、乙类 27 种、丙类 11 种；第四条说明传染性非典型肺炎和肺炭疽采取甲类传染病预防、控制措施。
